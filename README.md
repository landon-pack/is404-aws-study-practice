# IS404 AWS Study Lab

An interactive study site for AWS Academy Cloud Foundations Modules 1–8, organized into four midterm domains.

## Features

- 216 scenario-based practice questions across four sections
- Single-answer, multiple-select, and true/false questions
- Shuffled questions and answer choices
- Exact-match multiple-select scoring
- Answer explanations and official AWS reference links
- 10-question, 25-question, or full-section quizzes
- Topic results and retries for missed questions
- Responsive layout and keyboard-accessible controls

## Run locally

This app uses HTML, CSS, and JavaScript with no build dependencies.
Use a web server rather than opening index.html directly because the app fetches questions.json.

## Question bank

Edit questions.json. Each entry contains a section, topic, type, prompt, options, zero-indexed correct-answer indices, explanation, and AWS source URL. Practice questions were created with AI assistance and should be reviewed against the referenced documentation. They are independent study material, not official AWS exam questions.

## Scope

Sections cover Cloud Concepts; Security and Compliance; Cloud Technology and Services; and Billing, Pricing, and Support. AI/ML service identification, migration strategies, and support-plan tiers are excluded from this midterm practice bank.

Original course slides and instructor Kahoot files are not included.
